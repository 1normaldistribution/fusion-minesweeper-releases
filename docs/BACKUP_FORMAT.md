# JSON 备份格式

本文公开文件结构，便于备份工具互通；不包含游戏实现、题库或真实用户数据。

## 完整原生备份

编码为 UTF-8 JSON，顶层包含：

| 字段 | 类型 | 作用 |
| --- | --- | --- |
| schema | string | 固定为 `minesweeper-native-storage-v1` |
| entries | object | 应用的字符串键值数据 |

`entries` 的每个值必须是字符串。有些字符串内部又是 JSON，不能把它们直接改成顶层对象。应用保留未知键，便于兼容未来版本。导入时还会检查变体记录、进度档清单及相互引用；通过结构规范不等于通过完整业务校验。

[JSON Schema](../schemas/native-storage-v1.schema.json)只校验外层结构，不实现游戏规则。

## 其他文件类型

- `minesweeper-variants-v1`：单个变体进度。
- `minesweeper-classic-records-v1`：经典成绩记录。
- Windows 原作存档：使用相应导入路径解析，不等同于完整原生备份。

## 使用约定

完整进度导入会替换目标应用全部本地进度与设置。请先导出目标应用备份，不要用空示例覆盖真实进度。不要手工改写题目编号、进度引用或回放内容。

备份可能包含自定义进度档名称、成绩和操作记录。向公开 Issues 反馈时，优先提供复现步骤与已检查的截图，不要上传未经检查的完整私人备份。
