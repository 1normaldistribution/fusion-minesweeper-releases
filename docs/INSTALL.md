# 安装、升级与进度迁移

## 安装

1. 在 Releases 下载最新的 `fusion-minesweeper-版本号-android-arm64.apk`。系统要求为 Android 8.0+、ARM64。
2. 用系统安装器打开文件，根据提示允许当前来源安装。
3. 启动“Minesweeper · 融合版”，选择经典或变体玩法。

`Source code (zip/tar.gz)` 是 GitHub 自动打包的本仓库开发组件与文档，不是完整游戏源码或安装包。

## 从旧测试版迁移

正式版包名为 `com.minesweeper.fusion`，与“扫雷原生迁移测试”以及早期 Web 测试包分别安装。**安装正式版不会自动读取其他应用的私有进度。**

1. 在旧原生测试版中导出“完整进度”JSON，并保留原文件。旧版本若尚无完整备份入口，请先保留原应用，分别导出经典记录和变体备份，或联系作者协助迁移；不要先卸载。
2. 在正式版“变体设置 → 存档”选择“导入完整进度”，选取完整备份。
3. 核对确认信息后导入，再检查经典记录、变体进度档和设置。
4. 确认内容完整后再决定是否保留旧应用。无需为安装正式版先卸载旧应用。

变体单独备份只迁移变体数据；经典记录文件仅用于经典记录导入。不要把单项备份当成完整备份。导入完整备份会替换目标应用当前进度，操作前先备份目标应用。

## 后续升级

从本仓库下载同包名、同签名的新版本并覆盖安装。正常覆盖升级会保留数据，升级前仍建议导出 JSON 备份。出现签名冲突时不要直接卸载，请先保存备份并反馈。

## 核对下载文件

每个版本附带 `SHA256SUMS.txt`，可与下载 APK 的 SHA-256 比对。使用对应版本的校验文件；旧版校验值不能用于新版 APK。
