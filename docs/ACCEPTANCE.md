# 验收与复现清单

这是后续版本复查标准，不表示每项已经在所有机型上通过。每次测试应记录版本、设备、Android 版本、显示刷新率、设置、步骤和结果；源码检查、逻辑测试、屏幕截图和真机手感分别记录。

| 范围 | 检查标准 |
| --- | --- |
| 连续点击 | 多次快速点击能响应；两指分别点不同格子不互相吞掉操作；双指缩放不误开格 |
| 拖动和缩放 | 画面跟随，结束后能立即点击；与参考版本用同设备、同棋盘与同操作对照，不凭感觉宣称达标 |
| 首次开格 | 自动放大的时机、目标位置和过程与参考版本对照 |
| 后台恢复 | 等待后重新打开有画面，无需额外触摸恢复；计时、棋盘和操作模式保持正确 |
| 经典与变体布局 | 逐页核对工具栏、底部按钮、边距、字体、滚动范围和安全区域，不能只查一个模式 |
| 调色与教程 | 选色浮层不越界；切换不闪；滑条不遮字；教程再次点击能收起，不叠加展开 |
| 操作设置 | 对局底部操作模式与设置同步，退出、重进、后台恢复后仍正确 |
| 声音与失败效果 | 经典及变体分别核对音效、炸雷阶段、旗帜和覆盖层，不用单一截图代替过程核对 |
| 图鉴 | 各模式的新建、普通完成、完美完成和混合进度都与对应参考状态对照，不用虚构进度冒充通关 |
| 数据 | 导出、导入、错误文件拒绝、多进度档、最近删除和到期处理均检查；升级与测试前后比对真实进度 |
| 发布包 | 实际 APK 的签名、权限、版本、资源完整性、测试入口排除与安装启动单独检查 |

反馈性能问题时请注明操作过程和当前模式；如需录屏，可开启系统触点显示帮助复现。不要把录屏编码帧率、屏幕刷新率或重复绘制次数直接当成游戏有效帧率。
